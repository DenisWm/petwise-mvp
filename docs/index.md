# PetWise

PetWise is a concise reference microservice demonstrating a layered architecture, DDD-inspired modeling, and pragmatic production practices for service-oriented applications.

This documentation is aimed at developers and operators who need to run, integrate with, audit, or extend the service.

## Quick links

- **Getting started** — local and Docker quick start (run and test).
- **API reference** — canonical contract: `docs/api/openapi.yaml`.
- **Architecture** — system principles, module boundaries, and deployment considerations.
- **Contributing** — PR checklist and code quality rules.

## Production note

This repository is a reference implementation. For production deployments add security hardening, secrets management, observability (metrics, traces, logs), backups, and an automated CI/CD pipeline. See "Deployment checklist" in the Architecture section.

For issues or support open a GitHub issue in the project repository.
